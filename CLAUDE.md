## Blueprint capture

`casebook.yaml` links this project to the blueprints of the KI-Servicezentrum that it feeds. Read it at the start of a session. While it says `kickoff: open`, offer the kick-off interview (skill `kickoff-interview`, plugin kisz-code, planned). Write into a `blueprint-*/casebook/` folder only through the casebook skills and only after the engineer has confirmed the entry. Persons of the partner, contact data and text of partner documents never go into a casebook.
